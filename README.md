# 💫 About Me:
🚀 I’m currently working on deploying and optimizing video object segmentation models on NVIDIA Jetson Orin NX, pushing NanoSAM/EdgeTAM to real‑time on noisy, real‑world streams.<br>​🤝 I’m looking to collaborate on edge AI, computer vision, and applied deep learning projects where models have to run on actual hardware, not just look good in a paper.<br>​🧠 I’m looking for help with building more efficient attention and memory mechanisms for long video sequences, and exploring smarter distillation strategies for tiny models.<br>📚 I’m currently learning how to better fuse signal processing, V2X communication, and deep learning so that perception systems stay robust in messy environments.<br>💬 Ask me about running AI workflows on Jetson devices, turning 2D keypoints into 3D skeletons, or what it’s really like juggling research, teaching, and an Erasmus semester in Milan.<br>⚡ Fun fact: I once built a smart helmet that refuses to let you ride without wearing it and silently texts your emergency contacts if things go wrong.
